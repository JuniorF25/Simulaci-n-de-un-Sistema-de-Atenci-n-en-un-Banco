 Funcionamiento:

Hay dos colas:
Prioritaria (clientes con prioridad).
General (clientes normales).
Agregar clientes → Se colocan en la cola correspondiente.
Atender clientes → Se atienden primero los prioritarios, luego los generales.
Mostrar espera → Muestra cuántos clientes hay en cada cola.
Menú interactivo → Permite gestionar clientes desde la consola.
Es un sistema básico de turnos que prioriza a ciertos clientes
